# Portfolio Screenshot Guide — Applied Mathematical Intelligence

## Enable Screenshot Mode

1. Sidebar → **Portfolio Screenshot Mode**
2. Navigate to hero lab via sidebar radio

---

## Hero Page 1: Betting & Poker Lab (Analyze a Bet)

**Why:** Clear EV / probability / edge visualization — strongest quant decision story.

### Desktop

| Step | Action |
|------|--------|
| 1 | Sidebar → **Analyze a Bet** |
| 2 | Enable Screenshot Mode |
| 3 | Set win probability ~55%, decimal odds ~1.90 |
| 4 | Capture EV metrics row + probability tree + EV bar chart |

**Filename:** `01-betting-ev-lab.png`

### What makes it impressive

- Expected value calculation with plain-language verdict
- Visual probability tree and EV sensitivity chart
- Edge vs market implied probability

## Hero Page 2: AI Learning Lab (Train an AI)
